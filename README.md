# Balos Operations Dashboard

A modern, mobile-first web dashboard for Dubai real estate agencies powered by the Balos WhatsApp AI lead engine.

Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, and Supabase (`@supabase/ssr`).

## Features

- **Mobile-first design**: Optimized for agents on phones and desktop with Dubai-inspired palette and typography.
- **Strict security**: Uses only the Supabase anon key and signed-in user sessions with database RLS enforcement.
- **Executive Overview**: Real-time KPI metrics, median AI first-reply time, after-hours AI coverage, pipeline distribution, paused leads, and upcoming viewings.
- **Inbox & Handoff Management**: Live thread inspection, take over / hand back controls, 15-second auto-refresh.
- **Lead Intelligence**: Comprehensive searchable and filterable directory of leads with qualification details.
- **Viewings Management**: Track site visits, virtual Zoom walkthroughs (with direct Join links), and office consultations.
- **Property Inventory & Media Manager**: Admin management of all property columns, automatic Golden Visa qualification, image reordering with WhatsApp cover detection, and video upload constraints.
- **Agency Settings & Team Management**: Central business configuration and role/status assignment for agents.
